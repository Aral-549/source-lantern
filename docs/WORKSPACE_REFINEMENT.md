# Workspace refinement

1. Job: let a researcher organize sources, read documents and inspect evidence without competing panels.
2. Move: a quiet research desk; files gather in one paper folder, with the active document carrying the screen.
3. Real material: the active project's filenames, source text, reading progress and inspectable citations.
4. Accent: blue annotation ink on warm paper, inherited from the approved Des1gn scrapbook references.
5. Type: IBM Plex Sans for controls and prose, Source Serif 4 for document headings, Gochi Hand only on paper details.

Register: product. Motion lens: restraint; folder reveal and outgoing file fold follow the user's references. Existing approved workspace/project contracts govern behavior. This is a usability refinement under the user's awwwards invocation, preserving the user's earlier Anara structure and Des1gn typography. No new design approval gate is introduced.

Bencho sounds were assessed on 31 October. Its page states downloads need Pro; no licensed sound asset was supplied or added. Potential later choices: paperTap for selection, rustle for files, a quiet ready cue for completed reading. Default muted, explicit opt-in, no continuous or keystroke audio.
