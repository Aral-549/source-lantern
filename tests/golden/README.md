# Golden regression vectors

The JSON files here contain input-to-expected-output cases prepared in independent adversarial reviews of the contracts. No application or test runner exists yet. These files do not claim that tests have passed.

Existing cases are frozen ground truth. Add cases when needed; do not regenerate, rewrite, or delete existing cases without explicit human approval. Future runnable tests must consume these expected results rather than deriving expected values from the implementation under test.

Contract review remains pending. If a requested contract change would invalidate an existing golden case, identify that conflict and obtain explicit human approval before changing the case.
